# aquambiente
Consultoria ambiental, gestão de resíduos, monitorização e formação para empresas e comunidades comprometidas com o meio ambiente.

## Formulário de contacto

O formulário valida os dados e abre uma conversa no WhatsApp da Aquambiente
(`+244 945 428 008`) com a mensagem preenchida. A pessoa deve confirmar o envio
no WhatsApp. Não é necessária configuração de EmailJS ou reCAPTCHA.
